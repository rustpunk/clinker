# Error E127: Empty provenance query

## What it means

`clinker explain` received `--field` with an empty value. An empty query cannot
identify either a composition config parameter or a source-schema attribute,
so Clinker rejects it before looking at the compiled plan.

## Example

```console
clinker explain pipeline.yaml --field ''
# [E127] provenance query is empty
```

## How to fix

Pass a field shorthand or an exact versioned address:

```console
clinker explain pipeline.yaml --field 'risk.threshold'
clinker explain pipeline.yaml --field '/v1/config/nodes/risk/fields/threshold'
```

## Technical context

The query parser distinguishes an absent selector from a selector that failed
to resolve. This code is reserved for the empty-input case; E128 reports a
non-empty query with no match, and E129 reports ambiguous shorthand.
